2Upload your Skyward attendance and email report

This report gives each student's grade level, school email, family emails and this month's attendance.

How to create the Skyward PDF (first time: about 5 minutes; after that, about 1 minute)
  1. Open Student Management. In Skyward, click the arrow next to Home, then choose Students → Student Management.
  2. Open the Student Information report. Go to Reports, open Student Reports - RE, and click Student Information - SI.
  3. Make your own template once. In Student Information Templates, add a new template (or clone one) and name it YourLastName/emails and Attendance. Next month, just select it.
  4. Match these settings, then click Save and Print.
    Report By OptionsBy Teacher → Select Teachers → choose yourself. Print Students from Term: Any Term. Periods 00 to 99. Leave Print Dropped Students unchecked.
    Print Options to checkStudent Profile Information and Family Member Information. Leave everything else unchecked.
    Attendance TotalsChecked, with Display Attendance for Date Range checked. Start Date: the day after your last report. End Date: the 27th (or today).
    Print Only Attendance TotalsUnchecked, so each absence date is listed.
  5. Save it as a PDF. When the report finishes, open it and download or print it to PDF. Upload that file below.

3Upload your Edgenuity Group Progress page

This gives each student's courses, grades and percent complete.

How to save the Edgenuity page as a PDF (about 2 minutes)
  1. Open Group Progress Overview in Imagine Edgenuity for Educators.
  2. Set the filters:
    GroupAll Students
    ClassesYour name
    CoursesActive Courses
    StatusActive Students
    Display ByStudent
    SnapshotLatest
    Records Per PageALL (otherwise students are missed)
    Then click Search.
  3. Save as PDF: press Cmd+P (Mac) or Ctrl+P (Windows), set Destination to Save as PDF, and save. Upload that file below.
